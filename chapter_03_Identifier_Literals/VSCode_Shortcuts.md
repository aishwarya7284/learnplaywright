# VS Code Shortcuts (Windows)

## Basic Editing

- `Ctrl + C` : Copy
- `Ctrl + X` : Cut
- `Ctrl + V` : Paste
- `Ctrl + Z` : Undo
- `Ctrl + Y` : Redo
- `Ctrl + S` : Save file
- `Ctrl + Shift + S` : Save all files
- `Ctrl + /` : Toggle line comment
- `Alt + Shift + A` : Toggle block comment
- `Ctrl + Space` : Trigger suggestion / IntelliSense

## Navigation

- `Ctrl + P` : Quick open file
- `Ctrl + Shift + O` : Go to symbol in file
- `Ctrl + G` : Go to line
- `Ctrl + Tab` : Switch editor tabs
- `Ctrl + Shift + Tab` : Switch tabs in reverse
- `Ctrl + K Ctrl + O` : Open folder
- `Ctrl + B` : Toggle sidebar
- `Ctrl + \\` : Split editor
- `Ctrl + 1 / Ctrl + 2 / Ctrl + 3` : Focus editor group

## Search and Replace

- `Ctrl + F` : Find in file
- `Ctrl + H` : Replace in file
- `F3` / `Shift + F3` : Find next / previous
- `Ctrl + Shift + F` : Find in files
- `Ctrl + Shift + H` : Replace in files
- `Ctrl + D` : Add next occurrence to selection
- `Alt + Enter` : Select all occurrences

## Multi-cursor and Selection

- `Alt + Click` : Insert cursor
- `Ctrl + Alt + Down` / `Ctrl + Alt + Up` : Add cursor below / above
- `Ctrl + L` : Select current line
- `Ctrl + Shift + L` : Select all occurrences of current selection
- `Ctrl + Shift + \` : Jump to matching bracket

## Terminal

- `Ctrl + \\`` : Toggle integrated terminal
- `Ctrl + Shift + \\`` : Create new terminal
- `Ctrl + C` (in terminal) : Copy selected text
- `Ctrl + V` (in terminal) : Paste
- `Ctrl + Shift + C` : Open external terminal

## Debugging

- `F5` : Start / continue debugging
- `Shift + F5` : Stop debugging
- `F9` : Toggle breakpoint
- `F10` : Step over
- `F11` : Step into
- `Shift + F11` : Step out
- `Ctrl + Shift + D` : Open Debug view

## File and Window Management

- `Ctrl + N` : New file
- `Ctrl + W` : Close editor
- `Ctrl + K W` : Close all editors
- `Ctrl + Shift + N` : New window
- `Ctrl + Shift + W` : Close window
- `Ctrl + K Z` : Toggle zen mode

## Useful Commands

- `Ctrl + Shift + P` : Open command palette
- `Ctrl + K Ctrl + S` : Keyboard shortcuts reference
- `Ctrl + ` : Show problems panel
- `Ctrl + Shift + M` : Toggle problems panel
- `Ctrl + Shift + E` : Show Explorer
- `Ctrl + Shift + X` : Show Extensions
- `Ctrl + ` : Show Source Control panel

## Tips

- Use `Ctrl + Shift + P` and type a command name when you forget the shortcut.
- `Ctrl + P` is fast for opening files by name.
- Multi-cursor editing saves a lot of time when changing repeated code patterns.
