# Learn Playwright

This repository contains a growing collection of JavaScript, TypeScript, OOP, and Playwright learning examples.

## What is included

- JavaScript fundamentals and practice exercises
- Functions, arrays, strings, objects, and loops
- ES6+ concepts such as closures, higher-order functions, and templates
- Object-oriented programming concepts including classes, inheritance, encapsulation, and polymorphism
- TypeScript basics and interface examples
- Playwright automation examples and browser testing practice
