# Learn Playwright

This repository contains Playwright learning examples and JavaScript concept notes.

## Structure

- `chapter_01_Basics/` - Basic Playwright setup and verification scripts
- `chapter_02_Javascript_Concepts/` - JavaScript concept files
- `chapter_03_Identifier_Literals/` - Additional notes and reference files
- `chapter_04_JavaScript_Concept/` - Advanced JavaScript concept examples
- `chapter_05_Operators/` - Operator examples and comparisons
- `chapter_06_Statements/` - Statement examples, conditionals, and login examples
- `chapter_07_switch_statment/` - Switch statement and branching examples
- `chapter_08_userInput/` - User input and prompt handling examples
- `chapter_09_loops/` - Loop examples and iteration exercises
- `chapter_10_Array/` - Array operations and transformation examples
- `chapter_11_Functions/` - Function examples, scopes, closures, and higher-order functions
- `chapter_12_Strings/` - String operations, searching, transformation, and examples

## Notes

- Created on Windows environment
- Includes VS Code shortcut reference in `chapter_03_Identifier_Literals`

## Usage

Open this folder in VS Code and use the integrated terminal to run or edit files.
